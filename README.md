# 🎮 Neon Dodge

A fast-paced cyberpunk survival game built with React and developed using
voice-driven development with Whispr Flow.

## 🚀 About the Project

Neon Dodge is a browser-based arcade game where the player controls a
glowing neon character and avoids falling obstacles. The goal is to survive
as long as possible while achieving the highest score.

The project was developed using Whispr Flow to demonstrate how voice-driven
development can be used to create, modify, and debug a functional software
project.

## ✨ Features

- 🎮 Player movement
- 🔴 Falling obstacles
- 💥 Collision detection
- ❤️ Three lives
- 🏆 Score system
- 📈 Increasing difficulty
- 🔄 Restart game
- 🏅 High-score tracking
- 🌙 Cyberpunk dark theme
- 📱 Responsive interface
- ⌨️ Keyboard controls

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Vite
- Local Storage
- Whispr Flow
